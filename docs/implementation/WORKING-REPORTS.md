# Working case report safeguards

Date: 2026-10-17. R04-A enhances the existing social-case-management summary route and CSV. This is a working summary, not an approved official CEFMU or Study Report template.

The preview and CSV explicitly state DRAFT - Not approved for official release. They include working template version, authenticated preparer's name, source case record ID/update time and generation timestamp. No signature, approval, invented professional finding or official-release action is supplied. Metadata is generated from authorized server records and the authenticated user.

Existing reports.social.generate and case assignment/LGU checks remain required for preview and download. Draft status grants no new access. The original source allowlist remains unchanged: basic case/client header, current plan metadata, referral service/status dates and aftercare metadata. Restricted assessment, child participation, MDT content and general documents remain excluded. No new clinical/social case template or field is approved by this package.

Both responses use private, no-store headers. CSV values are consistently quoted, embedded quotes/newlines remain inside their cells, and formula prefixes after leading whitespace are neutralized. The filename is sanitized and starts with draft-. Generation/download audit records remain metadata only. No report is placed into offline packs or external services.

Browser testing identified an existing horizontally scrollable referrals table with no keyboard focus target; the table container is now an explicitly labelled keyboard-focusable region. This is a proportional accessibility repair, not an assertion that all report templates are complete.

Official forms, approved audience/field selection, pseudonymization policy, signatory/release workflow, approved PDF output, record snapshot/version retention and print/disclosure policy remain BLOCKED under B03/B04. Current template metadata identifies an on-demand working presentation, not a persisted approved document version. Owner/DPO/qualified casework review is still required.
