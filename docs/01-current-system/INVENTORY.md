# Legacy system inventory

The read-only reference ZIP was inspected without changing it. It is a Vue 3 SPA on Vercel with a Google Apps Script backend, Google Sheets records, Drive documents, IndexedDB queueing, and a D3 geographic visualization.

The functional baseline includes reports/screening, cases, referrals, activities/calendar, documents, consents, relationships, dashboard/quarterly reporting, form/data administration, audit logs, public dashboard, and role-aware navigation. Its documented state machines, SLA anchors, redaction tiers, and audit/soft-delete rules are the migration baseline.
