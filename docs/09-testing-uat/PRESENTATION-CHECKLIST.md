# Presentation checklist

1. Open `http://127.0.0.1:8000` and sign in as `admin@kalinga.test` using the local development password.
2. Open **Cases**. The 12 fictional `DEMO-KLG-2026-…` folders demonstrate several statuses and municipalities.
3. Open `DEMO-KLG-2026-0001` to show an assessment, case plan, monitoring visit, consent, relationship, referral, task, and audit timeline.
4. In **Client and case details**, change a field, use the Region → Province → Municipality/City → Barangay selectors, and save.
5. In **Referrals** and **Tasks**, show the controlled status actions. In **Insights**, show private aggregates; use `/public-dashboard` to show privacy-suppressed public aggregates.
6. Use **Archive case** only on a demonstration record. It is a soft archive: it hides the case from work lists while preserving the client and audit history.

All names, organizations, identifiers, phone numbers, notes, and narratives prefixed with `DEMO` are fictional presentation data. Do not enter actual protected case information into a presentation environment.
